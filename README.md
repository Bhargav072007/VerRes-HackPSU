# VerRes-HackPSU
VerRes is a pre-submission integrity check for research papers. It verifies every citation, tests every claim against its source, maps how the argument holds together, runs an AI peer-review panel and catches hidden prompts. Every finding comes with a receipt.

Partner B's Python evidence engine, setup instructions, provisional interfaces, and
integration requirements are documented in the
[backend handoff](api/app/verify/PARTNER_B_HANDOFF.md).
